# ميثاق المؤمن

تطبيق إسلامي قيد التطوير، هدفه جمع الأدوات والمحتوى الإسلامي الموثوق في مكان واحد.

## الخطة
- القرآن الكريم
- مواقيت الصلاة والأذان
- الأدعية والزيارات
- اتجاه القبلة
- مكتبة إسلامية
- مسائل شرعية مع توثيق المصادر

## الحالة الحالية
هذه نسخة تأسيسية للواجهة فقط. الميزات الدينية الفعلية ومصادر البيانات ما زالت قيد التطوير، ويجب التحقق من النصوص والمواقيت قبل الاعتماد عليها.

## التقنية
Flutter وDart، مع واجهة عربية من اليمين إلى اليسار.

## البناء
سيتم إعداد GitHub Actions لبناء نسخة Android APK تلقائياً عند تحديث الفرع الرئيسي.
